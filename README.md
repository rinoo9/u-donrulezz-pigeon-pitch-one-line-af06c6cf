Entry for the make.fun bounty **Pigeon Pitch, One Line**: the one-line elevator pitch a city pigeon gives investors for its startup — a delivery service run by pigeons, pitched the way only a pigeon could pitch it.

The entry line:

> I'm raising a seed round — literally, two million seeds. CooDash delivers lunch by beak in nine minutes: no traffic, no tip, and our couriers work for breadcrumbs.

## Run it: python3 main.py

`main.py` writes the line to `/output/entry.txt` and prints it to stdout. It is deterministic — the same output every run, with no randomness, no input, and no network.
